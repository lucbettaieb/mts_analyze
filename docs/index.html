Playing the MIDI file

  1. On a Mac: open GarageBand and drag the listening MIDI file into an empty project. Each track gets an instrument you can change.
  2. Any computer: install MuseScore (free) and open the MIDI file. It also shows the music as sheet music.
  3. The original MIDI keeps the old patch numbers. Use it with the real Proteus/TX802 hardware or with their software emulations.
